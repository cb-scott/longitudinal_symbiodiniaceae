# Coral Symbiont Switching Meta-Analysis

This repository contains the data-cleaning, environmental data extraction,
and statistical modeling pipeline for a ~26-year, multi-study meta-analysis
of coral-symbiont (Symbiodiniaceae) genus/subtype switching, its
relationship to environmental conditions (SST/heat stress, chlorophyll,
turbidity, precipitation), and its phylogenetic/trait-based structure
across host coral species.

Contact: Carly Scott, cabscott@unc.edu

## The Database
If you're here, you are probably looking for the final clean database generated by this project.
This database can be found both in "data/Long_Symbiont_Data_Manual.xslx" and "db/LongitudinalSymbiontDB_July132026.xlsx".
These files are equivalent.

I plan on keeping this database up to data as new studies are published and host it here. The July 13, 2026 ("data/Long_Symbiont_Data_manual.xslx") 
version is referenced in all scripts. New versions will be posted in the "db" folder, but are not directly referenced by the analysis pipeline.

The symbiont switching database contains 13 columns:

| Column | Type | Description |
|---|---|---|
| `SPECIES` | character | Host coral species, `GENUS_SPECIES` format, all caps (e.g. `PORITES_LOBATA`) |
| `COLONY_ID` | character | Unique colony identifier, prefixed by study code (e.g. `VN_PLOB_142`) |
| `STUDY` | character | Source study citation |
| `DATE` | EXCEL date | Sampling date, formatted as excel short date ("mm/dd/yy"). Exact date if reported; first of month if only month was given; 15th/30th if a vague timeframe ("mid-month"/"end-month") was reported |
| `GENUS` | character | Dominant/codominant (>10% relative abundance) Symbiodiniaceae genus at time of sampling (single letter, e.g. `C`; underscore-joined if codominant, e.g. `A_C`), always sorted alphabetically |
| `SUBTYPE` | character | Dominant/codominant (>10% relative abundance) SymPortal ITS2 profile or otherwise identified subtype, underscore-joined if multiple, always sorted alphanumerically |
| `BLEACHING_OBS` | character | Bleaching status at sampling (`Y`/`N`/` ` if not reported) |
| `DEAD` | character | Colony mortality status (`Y`/`N`/` ` if not reported) |
| `DEPTH_M` | numeric | Collection depth in meters |
| `LATITUDE` | numeric | Decimal degrees |
| `LONGITUDE` | numeric | Decimal degrees |
| `NOTES` and `NOTES2` | character | Any notes about the sampling design, study, or data extraction which might be relevant

## Repository Structure

```
scripts/   analysis scripts (numbered in pipeline order) + helper functions + Stan model code
data/      raw supplemental data, intermediate data products, and model fit objects
results/   figures and summary tables produced by the scripts
remote_run_resources/ scripts and intermediate data products to be run on a remote cluster (support pre-processing only)
db/ database versions
```

## Pipeline Order & How to Rerun

Scripts prefixed **`00`** are **pre-processing scripts used to build the
compiled database** (`data/Long_Symbiont_Data_Manual.xlsx`). You should
**not** need to run these to reproduce the modeling/results in this
project — the compiled database is provided directly, and scripts `01`
onward start from it.

Scripts **`01`–`04`** are the main analysis pipeline and can, in
principle, be started from any point, since intermediate data objects are
checked into `data/` at each stage.

| Script | Depends on output of |
|---|---|
| `00a_downloading_its2.sh` | — (raw download/reprocessing, run remotely) |
| `00b_RawData_PreDBClean.R` | `00a` (for Nunez et al. inputs only) |
| `01_EnvironmentalData.R` | `Long_Symbiont_Data_Manual.xlsx` (manually assembled from `00b` outputs) |
| `02_DataCleaning_Processing.R` | `01` (`data/EnvData_PCs.Rdata`) |
| `03_bayesian_models.R` | `02` (`data/LongZooxInputData_wEnv.Rdata`) |
| `04_MSM_modeling.R` | `02` (`data/LongZooxInputData_wEnv.Rdata`) |

## Scripts

### `00a_downloading_its2.sh`
**Purpose:** Retrieves raw sequencing reads and metadata for Nunez et al.
2023 from NCBI (insufficient metadata was available in the original
publication, so it was pulled from the associated BioProject), then runs
DADA2 + taxonomy assignment remotely on an HPC cluster.

- **Input:** NCBI BioProject accession `PRJNA794042`
- **Output:** `data/get.taxa.nunez.Rdata`, `data/Nunez_OTUtable.ITS2.Rdata`
- **Dependencies:** NCBI Entrez Direct tools (`esearch`/`efetch`/`xtract`), `fasterq-dump`, a `mamba`/`conda` environment named `ncbi`, a cluster job launcher (`flexlaunch.py`), R with **DADA2** installed
- **Note:** This is a cluster/remote script, not meant to be rerun locally. Referenced scripts `Nunez2023.ITS2.R` and `Nunez_2023asstax.ITS2.R` are not included in this repo.

### `00b_RawData_PreDBClean.R`
**Purpose:** Cleans each published study's raw supplemental data
(SymPortal profiles, ITS2 OTU tables, or per-study metadata sheets) into
the common schema used in `Long_Symbiont_Data_Manual.xlsx` (`SPECIES`,
`COLONY_ID`, `STUDY`, `DATE`, `GENUS`, `SUBTYPE`, `BLEACHING_OBS`, `DEAD`,
`DEPTH_M`, `LATITUDE`, `LONGITUDE`). Each per-study block writes its own
cleaned `.xlsx`, which is then manually merged into
`Long_Symbiont_Data_Manual.xlsx`. Not every source study is included here;
some reported data only in figure form and were extracted manually.

- **Inputs:** Many from individual study supplemental datasests; see script for data calls.
- **Dependencies:** `tidyverse`, `writexl`, `janitor`, `readxl`, `phyloseq`


### `01_EnvironmentalData.R`
**Purpose:** Pulls satellite environmental data (SST/degree heating weeks,
ocean color/turbidity, precipitation) for each sampling point via
`rerddap`, reduces the resulting variables to PC axes via PCA, and
generates diagnostic/summary figures (sample map, temporal coverage,
species observations). Per-point env queries are cached to
`data/envdata/` so the (slow, ~20+ min/variable) `rerddap` calls can be
skipped on rerun.

- **Input:** `data/Long_Symbiont_Data_Manual.xlsx`; `data/envdata/*.txt` (pre-computed, so the live queries can be skipped)
- **Output:** `data/EnvData_PCs.Rdata`
- **Dependencies:** `tidyverse`, `future`, `furrr`, `purrr`, `rerddap`, `zoo`, `vegan`, `maps`, `lubridate`, `ggforce`, `ggrepel`, `pheatmap` , `scripts/helpers.R`

### `02_DataCleaning_Processing.R`
**Purpose:** Loads the environmental PCs and manual database, generates
basic dataset summary stats and a by-study summary table, collapses
select species into recognized species complexes, joins environmental PCs
by lat/lon/date, and calls genus-level symbiont switching events per
colony (`NONE`/`MINOR`/`MAJOR`/`SUBTYPE_SWITCH`) based on sequential
sampling within each colony.

- **Input:** `data/EnvData_PCs.Rdata`, `data/Long_Symbiont_Data_Manual.xlsx`
- **Output:** `results/StudySummary.xlsx`, `data/LongZooxInputData_wEnv.Rdata`
- **Dependencies:** `tidyverse`

### `03_bayesian_models.R`
**Purpose:** Builds phylogenetic and trait covariance matrices for the
host coral species, then fits three Stan models via a custom Dirichlet
variance-partition prior: an ordinal (cumulative logit) model of
switching severity, a Bernoulli model of binary switching (robustness
check), and a Bernoulli model restricted to each colony's first switch
(for comparison to the `msm` annual transition estimates). Produces
convergence diagnostics, fixed/random effect summaries, variance
partition estimates, and species-level switching predictions.

- **Input:** `data/LongZooxInputData_wEnv.Rdata`, `data/mtree.trees`, `data/McMillianTraitPCs.Rdata`, `scripts/coral_dirichlet_partition.stan`, `scripts/coral_dirichlet_partition_bernoulli.stan`
- **Output:** `data/stan_dirichlet_explicit.RDS`, `data/stan_dirichlet_explicit_bernoulli.RDS`, `data/stan_dirichlet_explicit_bernoulli_first.RDS`, `results/FE_DiriOrdinal.xlsx`, `results/RE_DiriOrdinal.xlsx`, `results/FE_Bernoulli.xlsx`, `results/RE_Bernoulli.xlsx`, `results/RE_BernoulliFirst.xlsx`
- **Dependencies:** `tidyverse`, `brms`, `cmdstanr` (+ a working CmdStan installation), `ggtree`, `patchwork`, `ape`, `phytools`, `phangorn`, `posterior`, `Matrix`, `bayesplot`, `tidybayes`, `ggdist`, `Ternary`, `viridisLite`, `writexl`, `scripts/helpers.R`
- **Note:** Model fitting (~20–45 min per model) can be skipped  by loading the provided `.RDS` fit objects from Zenodo repository (the RDS files with saved model outputs are too large to be hosted on github)

### `04_MSM_modeling.R`
**Purpose:** Fits multistate Markov (`msm`) models to genus-level
switching: first a two-state (baseline vs. switched) model of annual
switching/reversion probability as a function of environmental PCs, then
a four-state (A/B/C/D) pairwise transition-rate model with mixed-genotype
states censored. Produces hazard ratio plots, transition-rate network
diagrams, and pairwise switching-rate forest plots.

- **Input:** `data/LongZooxInputData_wEnv.Rdata`
- **Output:** none saved to `data/`; scripts are quick to run
- **Dependencies:** `msm`, `tidyverse`, `igraph`, `scripts/helpers.R`

### `helpers.R`
Not run directly; sourced by script. Contains shared functions:
`assign_ocean_basin()`, `compute_species_switching()`,
`summarise_switching()`, `plot_switching_tree()`, `extract_re()` (all
actively used), plus several additional utilities
(`plot_species_effects()`, `plot_species_effects_phylo()`,
`plot_species_effects_grid()`, `graft_missing_species()`,
`dirichlet_soft_stanvars()`, `add_epred_draws_manual()`,
`rordered_logistic_vec()`) that aren't currently called by any numbered
script — kept for reference/earlier modeling iterations.

### `coral_dirichlet_partition.stan` / `coral_dirichlet_partition_bernoulli.stan`
Custom Stan model code (adapted from `brms`-generated Stan code) implementing
the explicit Dirichlet(1,1,1) partition prior on species-level variance
(phylogenetic, residual, trait), for the ordinal and Bernoulli response
models respectively. Called from `03_bayesian_models.R` via `cmdstanr::cmdstan_model()`.
